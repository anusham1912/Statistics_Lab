Discrete Probability Distributions Laboratory

Welcome to the undergraduate AIML laboratory web application. This interactive tool helps students explore discrete random variables and probability distributions through mathematical formulas, real-time parameter configuration, probability calculators, statistical summaries, and dynamic visualizations.

Module 1

Binomial Distribution

Models the number of successes in a fixed number of independent trials with constant success probability.

Module 2

Poisson Distribution

Models the number of events occurring in a fixed interval when events occur independently at a constant rate.

Future Module

Geometric Distribution

Models the number of independent trials until the first success. Planned for future curriculum update.

Laboratory Exercises

Guided interactive exercises with pre-configured parameters to test analytical expectations against real-time computations.

Module 1

Binomial Distribution

Models the number of successes in a fixed number of independent trials with identical success probability.

Notation
X ~ Binomial(n, p)

Please enter a positive integer for n.

Accepts positive integers only.

Value must be between 0 and 1 inclusive.

Failure probability (1 - p) = 0.65
