Discrete Probability Distributions

Welcome to the interactive Artificial Intelligence and Machine Learning (AIML) laboratory module focused on discrete probability distributions. In probabilistic modeling and machine learning, discrete distributions form the foundation for naive Bayes classifiers, language models, stochastic optimization, and discrete event simulations.

Lab Overview & Instructions

Use the navigation menu above to access individual modules for the Binomial, Poisson, and Geometric distributions. Each module features live parameter tuning, analytical moment calculations, PMF and CDF probability calculators, dynamic SVG visualizations with mean reference lines, and structured laboratory exercises with validation.

Binomial Distribution

Models the number of successes in a fixed number of independent Bernoulli trials with constant success probability.

X ~ Binomial(n, p)

Poisson Distribution

Models the number of discrete events occurring in a fixed interval of time or space given a constant average rate.

X ~ Poisson(λ)

Geometric Distribution

Models the number of independent Bernoulli trials required to observe the first success.

X ~ Geometric(p)

Geometric Distribution Module

Models the number of independent Bernoulli trials $X$ required to obtain the first success, with constant success probability $p$.

X ~ Geometric(p),    P(X = k) = (1-p)^(k-1) * p,    k = 1, 2, 3, ...
